使用 Windows 中文字体及 TeX Live，在本目录下连续执行三次：

```powershell
xelatex -interaction=nonstopmode -halt-on-error "结课报告_目录修正版.tex"
xelatex -interaction=nonstopmode -halt-on-error "结课报告_目录修正版.tex"
xelatex -interaction=nonstopmode -halt-on-error "结课报告_目录修正版.tex"
```

文献条目已内嵌于主文件，无需另行运行 BibTeX。保留主文件和 `assets/` 的相对目录关系；`assets/details/` 为局部实验结果图，`assets/papers/` 为论文图。所有引用配图均包含在本分支中，旧版报告、预览图、构建日志和临时压缩包未重复上传。
